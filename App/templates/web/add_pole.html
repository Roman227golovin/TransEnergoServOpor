Изменить количество листов

Для каждого листа укажи его номер по порядку (1, 2, …) или точное имя (необязательно — по умолчанию активный лист файла). Для каждого нужного поля укажи столбец («C»), диапазон столбцов («C:E») или — если записи идут не сразу после заголовка или заканчиваются раньше конца листа — точный диапазон ячеек со строками («C9:E28»; строку нужно указать с ОБЕИХ сторон двоеточия, иначе она не учтётся). Если строки указаны хотя бы у одного поля на листе — читаются именно они, а «Номер строки с заголовками» ниже можно не заполнять. Если ни у одного поля строки не указаны — данные читаются от следующей строки после «Номера строки с заголовками» и до конца листа (полностью пустые строки пропускаются). Поля без указанного столбца останутся пустыми — их можно дозаполнить вручную после импорта. Если в файле нет отдельного столбца для дирекции — впиши её вручную в поле ниже (актуально для роли ТЭ, у которой нет своей дирекции по умолчанию); для района КС/станции без столбца подставятся значения твоего аккаунта (если они заполнены). Незаполненный блок листа просто игнорируется.
